## Analysis Categories

### Structure
- Section breakdown (Intro, Verse, Drop, etc.)
- Section lengths
- Pattern repetition
- Unique sections
- Transition types

### Energy
- Energy curve per section
- Bass movement patterns
- Drum density
- Automation presence

### Bass
- Layer count
- Layer functions
- Modulation types
- Sub-body relationship
- Movement frequency

### Drums
- Kick character
- Snare character
- Hi-hat patterns
- Percussion density
- Swing/groove feel

### Stereo
- Width per element
- Center content
- Side content
- Mono compatibility notes

### Dynamics
- Compression style
- Dynamic range
- Peak behavior
- Impact moments

### FX
- FX types used
- Automation presence
- Transition FX
- Atmosphere layers

### Automation
- Filter automation
- Volume automation
- Effect automation
- Energy rides

### Mix
- Frequency balance
- Low end character
- High end character
- Staging

### Master
- Loudness level
- EQ character
- Stereo width
- Limiting style
