# Sound Design Principles

---

## Core Principle
> Every sound has one function. Design for that function.

---

## Layer Functions

| Function | Priority | Examples |
|----------|----------|----------|
| Sub | 1 | Fundamental, impact |
| Body | 2 | Harmonics, weight |
| Movement | 3 | Modulation, interest |
| Noise | 4 | Texture, edge |
| Stereo | 5 | Width, space |
| Air | 6 | Presence, air |
| Texture | 7 | Character |
| FX | 8 | Impact, transition |

---

## Synthesis Types

### Subtractive
- Oscillator → Filter → Amplitude
- Best for: Fundamental sounds
- Tools: Analog Obsidian, Diva

### Additive
- Harmonic series building
- Best for: Complex tones
- Tools: Serum additive, Omnisphere

### FM
- Operator modulation
- Best for: metallic, glassy sounds
- Tools: Serum FM, FM8, Phase Plant

### Wavetable
- Waveform morphing
- Best for: evolving textures
- Tools: Serum, Phase Plant, Vital

### Granular
- Sample manipulation
- Best for: textures, atmospheres
- Tools: Omnisphere, PaulXStretch

---

## Oscillator Strategies

### Basic
- Single oscillator
- Clean, simple
- Best for: sub, fundamental

### Detuned
- 2 oscillators slightly detuned
- Width, thickness
- Best for: body, pads

### Unison
- Multiple oscillators spread
- Wide, powerful
- Best for: leads, impact sounds

### Ring Mod
- Oscillator multiplication
- Metallic, glassy
- Best for: accents, textures

---

## Filter Strategies

### Low-Pass
- Removes highs
- Most common for bass
- Resonance for character

### High-Pass
- Removes lows
- For non-bass elements
- Clean up mud

### Band-Pass
- Isolates frequencies
- For accents
- For specific character

### Notch
- Removes specific frequency
- Problem frequency removal
- Surgical use

---

## Modulation Strategies

### Envelope Modulation
- Attack, decay, sustain, release
- Transient shaping
- Movement in sound

### LFO Modulation
- Rhythmic movement
- Filter sweeps
- Tremolo, vibrato

### Velocity Modulation
- Expression control
- Dynamic variation
- Humanization

### Modulation Matrix
- Complex routing
- Multiple destinations
- Layered modulation

---

## Distortion Strategies

### Saturation
- Soft clipping
- Harmonic enhancement
- Warmth, character

### Distortion
- Hard clipping
- Aggressive character
- Edge, aggression

### Bitcrushing
- Reduced bit depth
- Digital character
- Lo-fi texture

### Waveshaping
- Custom distortion curves
- Specific harmonic content
- Surgical distortion

---

## Design Workflow

### 1. Define Function
- What does this sound do?
- Where does it sit in mix?
- What's its priority?

### 2. Choose Synthesis Type
- What creates this sound best?
- Keep it simple first
- Add complexity only if needed

### 3. Build Foundation
- Oscillator selection
- Basic envelope
- Core frequency

### 4. Add Character
- Filtering
- Distortion
- Modulation

### 5. Test in Mix
- Solo with other elements
- Check function
- Adjust for context

### 6. Document
- Preset name with notes
- Macro settings
- Layer functions
