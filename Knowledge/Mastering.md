# Mastering

---

## Core Principle
> Fix the mix before mastering

---

## Master Chain

### EQ
- Gentle corrective EQ
- 1-3 dB adjustments
- Broad curves
- Fix frequency issues

### Saturation
- Tape emulation
- Adds harmonics
- Increases perceived loudness
- Subtle settings (2-5%)

### Compression
- Ratio: 1.5:1 - 2:1
- Fast attack (1-5 ms)
- Slow release (100-200 ms)
- Purpose: glue, consistency

### Limiter
- Ceiling: -1 dB true peak
- Input gain controls loudness
- Release: auto or 5-10 ms
- Purpose: prevent clipping

### Stereo Enhancement
- Mid-side processing
- Subtle width increase (5-15%)
- Bass to mono redirect

---

## Loudness Targets

| Style | LUFS |
|-------|------|
| Radio/Club | -5 to -3 |
| Streaming | -7 to -5 |
| Atmospheric | -10 to -8 |

### True Peak
- Maximum: -1 dBTP
- Safe: -1.5 dBTP

---

## Master Check

1. Play in mono
2. Check frequency balance
3. Compare to reference
4. Check on multiple systems
5. Listen for distortion
6. Verify mono compatibility

---

## What NOT To Do In Mastering

- Fix a bad mix
- Add bass that isn't there
- Excessive limiting
- Remove all dynamics
- Over-process
