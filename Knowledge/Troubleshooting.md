# Troubleshooting System

---

## Problem Workflow

```
Problem
    ↓
Possible Causes
    ↓
Tests
    ↓
Decision Tree
    ↓
Solutions
```

---

## Weak Bass

### Possible Causes
- Sub level too low
- Kick masking sub
- EQ masking
- Poor monitoring
- Too much low-mid
- Phase cancellation

### Tests
1. Solo sub layer, check meter
2. Solo kick, check frequency overlap
3. Bypass all EQ on bass
4. Check in mono
5. Check on different system

### Solutions
- Increase sub gain 3-6 dB
- Pitch-lock kick to sub
- Sidechain bass to kick
- Cut 100-200 Hz on bass
- Invert polarity on parallel

---

## Weak Kick

### Possible Causes
- Attack too soft
- Body missing
- Pitch not matched
- Compression too heavy
- Bass masking

### Tests
1. Check attack transient
2. Check body at 60-80 Hz
3. Check relationship with bass
4. Bypass compression

### Solutions
- Increase attack envelope
- Boost 50-80 Hz
- Pitch-lock to track key
- Reduce compression attack time
- Sidechain bass to kick

---

## Muddy Mix

### Possible Causes
- Unclear 200-400 Hz
- Bass too prominent
- Too many elements in low end
- Poor EQ choices
- Lack of high-pass filtering

### Tests
1. Solo low end, identify problems
2. Solo mid range
3. Check frequency clash points
4. Compare to reference

### Solutions
- High-pass all non-bass elements
- Cut 200-400 Hz on competing elements
- Reduce bass decay
- Clear space for kick
- Reference comparison

---

## Phase Issues

### Possible Causes
- Sub and kick fighting
- Multiple bass layers
- Polarity issues
- Parallel processing delay
- Compressor attack time

### Tests
1. Solo kick and sub in mono
2. Check polarity on both
3. Check delay settings on parallel
4. Listen for cancellation

### Solutions
- Invert polarity on one channel
- Align transients manually
- Adjust compressor attack
- Use shortest delay on parallel
- Consider frequency splitting

---

## Empty Arrangement

### Possible Causes
- Too much space between sections
- Transitions missing
- Energy flat
- No build/crescendo
- Sections too similar

### Tests
1. Map energy curve
2. Identify transition points
3. Check section variety
4. Time sections

### Solutions
- Add risers before drops
- Build energy gradually
- Vary section content
- Add transitional FX
- Use filter automation

---

## Low Energy

### Possible Causes
- Compression too gentle
- Arrangement too static
- No dynamics contrast
- Filter too closed
- Mixing too polite

### Tests
1. Check dynamics range
2. Check arrangement flow
3. Compare to reference
4. Check frequency balance

### Solutions
- Increase compression ratio
- Add dynamic elements
- Automate filter/cutoff
- Add impact moments
- Reference comparison
