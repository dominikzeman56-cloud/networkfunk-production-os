# Automation

---

## Core Principle
> Movement creates energy

---

## Automation Types

### Filter Automation
- Low-pass filter sweep for energy rise
- High-pass for breakdown clarity
- Band-pass for accent moments
- Frequency: 20 Hz - 20 kHz range

### Volume Automation
- Ducking for impact (kick, snare)
- Ride ups for builds
- Fade outs for endings
- Prevents static mixes

### Effect Automation
- Reverb wet/dry mix
- Delay feedback
- Distortion amount
- Modulation depth

### Pitch Automation
- Sub bass movement
- Lead accents
- Risers

---

## Common Patterns

### Build
1. Filter sweeps up (4-8 bars)
2. Volume rides up slightly
3. Add reverb/delay
4. Bass increases

### Drop Entrance
1. Filter snaps open
2. Volume spike
3. Reverb drops
4. Bass full

### Breakdown
1. Filter sweeps down
2. Reverb increases
3. Volume softer
4. Atmosphere prominent

---

## Workflow

1. Write basic arrangement first
2. First automation pass (big moves)
3. Second pass (refinement)
4. Third pass (ear candy)
