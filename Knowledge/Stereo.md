# Stereo Field

---

## Core Principle
> Center = impact, Sides = atmosphere

---

## Stereo Rules

| Element | Position | Reason |
|---------|----------|--------|
| Kick | Center | Impact, translation |
| Sub | Center | Mono bass essential |
| Bass (non-sub) | ±20-40% | Width enhancement |
| Snare | Center | Impact |
| Hi-hats | ±30-60% | Space, groove |
| Pads | ±80-100% | Atmosphere |
| Leads | ±20-40% | Clarity + presence |
| FX | ±70-100% | Space |

---

## Width Techniques

### Mid-Side EQ
- Boost sides at 2-8 kHz for air
- Cut mud in sides (200-400 Hz)
- Keep sub range mono

### Stereo Chorus
- Creates width from mono source
- Use on bass body layer
- Subtle settings (10-20%)

### Haas Delay
- Delay one channel 10-40 ms
- Creates pseudo-stereo
- Check mono compatibility

### Stereo Imaging Plugins
- Width control
- Bass mono redirect
- Solo side check

---

## Mono Compatibility Check

1. Play in mono
2. Listen for:
   - Bass disappearance
   - Phase issues
   - Width collapse
3. Fix problematic elements
4. Redirect bass to mono
5. Check side content

---

## Common Problems

- Bass too wide → Redirect to mono
- Phasing on bass → Check polarity
- Weak mono sound → Enhance center
- Empty sides → Add atmosphere
- Harsh highs in mono → Check sides EQ
