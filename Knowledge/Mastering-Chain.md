# Mastering Chain

---

## Core Principle
> Fix mix issues before mastering. Mastering enhances, it doesn't fix.

---

## Mastering Order

1. **Analysis** - Check mix balance
2. **EQ** - Gentle corrective
3. **Saturation** - Subtle harmonics
4. **Compression** - Gentle glue
5. **Limiting** - Peak control
6. **Dither** - If reducing bit depth

---

## Chain Breakdown

### Step 1: EQ
**Purpose:** Corrective, gentle
**Settings:**
- High-pass: 20-30 Hz
- Low shelf: 20-50 Hz if muddy
- Gentle boost at 5-10 kHz if dull
- Air boost at 12-16 kHz
- Cuts: 2-3 dB max, broad curves

**Plugins:** EQ8, Pro-Q 3, FabFilter

### Step 2: Saturation
**Purpose:** Add warmth, harmonics
**Settings:**
- Tape or Tube style
- Drive: 2-5%
- Output: Match input level
- Subtle, musical

**Plugins:** Saturation Knob, Decapitator, Tube-Tech

### Step 3: Compression
**Purpose:** Glue, consistency
**Settings:**
- Ratio: 1.5:1-2:1
- Attack: 5-10 ms
- Release: Auto or 200ms+
- Gain reduction: 1-3 dB
- Makeup: Auto match

**Plugins:** Pro-C, LA-2A, Distressor

### Step 4: Limiting
**Purpose:** Prevent clipping, control peaks
**Settings:**
- Ceiling: -1.0 dBTP (never higher)
- Input gain: Controls loudness
- Release: Auto or 5-10 ms
- Lookahead: 1-5 ms

**Plugins:** L2, FabFilter Pro-L, Ozone

### Step 5: Dither
**Purpose:** Reduce bit depth gracefully
**When:** If reducing from 24-bit to 16-bit
**Type:** TPDF dither
**Dithered file only, not for streaming

**Plugins:** Ozone Dither, Dither

## Quick Reference

| Stage | Purpose | Typical Settings |
|-------|---------|------------------|
| High-pass | Clean sub-bass | 20-30 Hz |
| Low shelf | Remove mud | 30-80 Hz, -2 dB |
| Air boost | Brilliance | 12-16 kHz, +2 dB |
| Saturation | Warmth | 2-5% drive |
| Compression | Glue | 1.5:1, 5-10ms attack |
| Limiting | Peaks | -1 dBTP ceiling |

---

## Tips

1. Keep reduction to 1-3 dB on compressor
2. Limit at -1 dBTP max
3. Check on multiple systems
4. Compare to reference
5. A/B against original
6. Don't over-process
7. If it doesn't sound better, don't do it
