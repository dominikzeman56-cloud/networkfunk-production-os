# Preset Analysis Framework

---

## Core Principle
> Presets are starting points. Extract production patterns, not parameter values.

---

## Analysis Categories

### Oscillator Strategy
- Waveforms used
- Detune approach
- Unison configuration
- FM/ring mod usage
- Phase modulation

### Routing Strategy
- Signal flow
- Parallel processing
- Send/return usage
- Buss routing
- Output chain

### Filter Strategy
- Filter type
- Cutoff movement
- Resonance settings
- Drive before/after
- Multiple filters

### Modulation Strategy
- LFO targets
- Envelope shapes
- Modulation matrix
- Velocity mapping
- Randomization

### FX Strategy
- Distortion type
- EQ placement
- Compression style
- Reverb/delays
- Width processing

### Macro Design
- Macro assignments
- Useful ranges
- Performance mapping
- Expression control

## Lesson Extraction

### For Each Preset:
1. What does it do well?
2. What layer function does it serve?
3. How would I modify it?
4. What principles does it demonstrate?
