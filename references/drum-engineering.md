# Drum Engineering

Purpose: build neurofunk drums that create punch, grid, groove, and movement without overfilling the track.

## Philosophy

Drums are the skeleton of the drop. Bass can be complex only when the drum grid is clear.

Do not wait until the end to make drums hit. Design kick, snare, and bass together.

## Kick

Main jobs:

- transient definition
- low punch
- compatibility with sub
- groove anchor

Checks:

- [ ] Kick still reads when bass is active.
- [ ] Tail is not blurring the sub.
- [ ] Pitch or body does not fight the bass fundamental.
- [ ] Clipping/saturation adds density without flattening the groove.

## Snare

Main jobs:

- backbeat authority
- transient
- body
- noise/tail
- width and room impression

Layer by function:

- transient
- body
- noise
- tail
- optional clap/room layer

Checks:

- [ ] Transient cuts without harshness.
- [ ] Body is audible on small speakers.
- [ ] Tail does not cover bass articulation.
- [ ] Width does not weaken mono impact.

## Hats, Ghosts, And Percussion

Use these to create motion, not clutter.

- Hats define speed.
- Ghost snares imply groove.
- Percussion creates micro-variation.
- Fills reset attention before section changes.

## Drum Bus

Typical decisions:

- subtle saturation for density
- clipping for transient control
- compression only when it improves groove or glue
- EQ for low-mid cleanup and top-end shape

Avoid solving weak sample choice with too much bus processing.

## Groove Checklist

- [ ] Kick and snare communicate the rhythm without bass.
- [ ] Hats imply momentum.
- [ ] Ghosts are felt more than noticed.
- [ ] Fills mark arrangement changes.
- [ ] Drum bus still has transient life.
- [ ] The bass phrase locks to the drum accents.
