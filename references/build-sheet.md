## Bass Archetype Choice

```text
Need controlled rhythmic speech?
  -> Growl

Need sustained pressure and harmonic width?
  -> Reese

Need both movement and weight?
  -> Hybrid

Need club-forward simplicity?
  -> Roller / neurobounce

Need metallic aggression and precision?
  -> Tech / FM-led growl
```

## Session Planning

Use one clear session goal:

- "Finish Drop A groove."
- "Create three bass call-and-response variations."
- "Make transition into Drop A work."
- "Clean low end and export rough mix."

Avoid goals like "finish track" unless the track is already close.

## Progress Snapshot

```text
Composition: [ ] sketch [ ] hook [ ] motifs stable
Drums:       [ ] kick [ ] snare [ ] groove [ ] fills
Bass:        [ ] sub [ ] main [ ] variations [ ] print
Arrangement: [ ] intro [ ] drop A [ ] break [ ] drop B [ ] outro
Automation:  [ ] bass [ ] FX [ ] energy [ ] transitions
Mix:         [ ] low end [ ] drums [ ] stereo [ ] reference
Export:      [ ] loop [ ] full rough [ ] mix v1 [ ] master check
```

## Anti-Drift Rules

- If the loop is not working, do not fix it with mastering.
- If the bass is exciting soloed but weak in context, redesign in context.
- If the drop feels flat, check rhythm, contrast, and automation before adding more layers.
- If the session has no goal, write one before touching plugins.
