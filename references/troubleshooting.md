# Troubleshooting

Purpose: diagnose production problems by cause, not by adding random processing.

## Bass Is Not Aggressive Enough

```text
Is the rhythm strong?
  no -> rewrite MIDI or resampled phrase
  yes -> continue

Is the midrange speaking?
  no -> add FM, filter movement, distortion, or wavetable contrast
  yes -> continue

Is it too smooth?
  yes -> add transient detail, sharper envelopes, or edited audio cuts

Is it too full but not clear?
  yes -> remove layers, carve low mids, separate functions
```

## Kick Disappears

Check in order:

1. kick sample or synthesis
2. kick tail length
3. kick-sub phase
4. sub envelope
5. sidechain timing
6. bass masking
7. clipping or limiter flattening

Do not start with mastering.

## Snare Feels Small

```text
No transient?
  -> add or replace transient layer

No body?
  -> add body layer or tune existing body

No width?
  -> add width to tail/noise, not necessarily transient

Too harsh?
  -> reduce upper-mid buildup before increasing loudness
```

## Drop Has No Energy

Diagnose:

- Is the groove clear without bass?
- Is the bass rhythm answering the drums?
- Is there contrast before the drop?
- Is automation doing anything meaningful?
- Are too many layers playing the same function?
- Does the drop peak too early?

Fix order:

1. arrangement contrast
2. drum groove
3. bass phrase
4. transition into drop
5. automation
6. mix density

## Low End Is Messy

```text
Mute mid bass.
Does kick + sub work?
  no -> fix phase, envelope, tuning, sidechain
  yes -> mid bass is the problem

Bring mid bass back.
Does low-mid blur appear?
  yes -> high-pass, EQ, shorten notes, or split layers
```

## Stereo Feels Wide But Weak

- Mono the track.
- Check what disappears.
- Move width upward.
- Keep sub stable.
- Narrow low-mid information.
- Use stereo as contrast, not a permanent fog.
