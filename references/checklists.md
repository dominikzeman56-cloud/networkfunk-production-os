# Checklists

Purpose: provide quick gates for production sessions.

## New Project

- [ ] Build sheet filled.
- [ ] Reference tracks loaded and level matched.
- [ ] Session goal chosen.
- [ ] Ableton template groups ready.
- [ ] First export target defined.

## Drop A

- [ ] Kick and snare work without bass.
- [ ] Sub works with kick.
- [ ] Main bass has a clear rhythmic role.
- [ ] Call-and-response exists or the loop intentionally stays minimal.
- [ ] Transition into drop creates contrast.
- [ ] At least one automation move changes energy.
- [ ] Rough export sounds like a track section, not a sound-design demo.

## Bass Design

- [ ] Archetype selected.
- [ ] Sub separated or deliberately integrated.
- [ ] Mid bass works in context.
- [ ] Movement is intentional.
- [ ] Stereo does not damage mono.
- [ ] Best ideas are printed or saved.

## Arrangement

- [ ] Intro establishes world or tension.
- [ ] Build earns the drop.
- [ ] Drop A states the main idea.
- [ ] Variation prevents fatigue.
- [ ] Break changes perspective.
- [ ] Drop B differs from Drop A.
- [ ] Outro gives a DJ-friendly or musical exit.

## Mix

- [ ] Reference checked at matched level.
- [ ] Kick, snare, sub, and bass relationship works.
- [ ] Low mids are not crowded.
- [ ] Harshness is controlled before limiting.
- [ ] Stereo image survives mono check.
- [ ] Drum bus still has movement.
- [ ] Premaster has headroom before final limiter.

## Master Preview

- [ ] Loudness does not destroy transients.
- [ ] Bass remains stable.
- [ ] Snare still hits.
- [ ] Highs are exciting, not painful.
- [ ] Drop and breakdown still contrast.
- [ ] Export checked outside Ableton.

## Release Prep

- [ ] Final mix export archived.
- [ ] Master export archived.
- [ ] Stems or important prints saved.
- [ ] Project version labeled.
- [ ] Notes updated with lessons learned.
