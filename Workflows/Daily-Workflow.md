# Daily Production Workflow

---

## Pre-Session (10 min)

### Mental Preparation
- [ ] Clear distractions
- [ ] Review yesterday's progress
- [ ] Set intention for today

### Workspace Setup
- [ ] Open Ableton
- [ ] Load production template
- [ ] Open NPOS Dashboard
- [ ] Set timer (90 min max)

---

## Session Structure

### Session Goal
> One specific, achievable objective

### Work Blocks (30 min each)

#### Block 1: Deep Work
- [ ] Work on primary objective
- [ ] No distractions
- [ ] Stay in context

#### Block 2: Continue or Review
- [ ] Continue if in flow
- [ ] Review if stuck
- [ ] Make decisions, don't analyze

#### Block 3: Wrap Up
- [ ] Save version
- [ ] Note what worked
- [ ] Note problems
- [ ] Set tomorrow's goal

---

## When Stuck (15 min rule)

1. **Try one more approach** (5 min)
2. **If still stuck, document:**
   - What I tried
   - What didn't work
   - Hypothesis for why
3. **Take a break** (10 min)
4. **Return with fresh ears**

---

## Session Types

### Creative Session
- [ ] Generate ideas
- [ ] Experiment freely
- [ ] Don't judge quality
- [ ] Capture everything

### Production Session
- [ ] Execute defined plan
- [ ] Focus on details
- [ ] Make concrete decisions
- [ ] Document choices

### Mixing Session
- [ ] Start with reference
- [ ] Work L-R (kick-bass first)
- [ ] Take breaks every 30 min
- [ ] Don't mix tired

### Finishing Session
- [ ] Export stems
- [ ] Check on multiple systems
- [ ] Take breaks
- [ ] Sleep on final decisions

---

## Post-Session (5 min)

- [ ] Save and backup
- [ ] Update Dashboard
- [ ] Log session in Journal
- [ ] Set tomorrow's goal
