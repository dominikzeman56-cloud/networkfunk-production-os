## Key Takeaways

### Project Structure
- 3 separate Q-Base projects for the song
- Main Q-Base project (arrangement, sound design)
- Mixing project for vocals (processed vocal stem to save CPU)
- Musical writing project (compositional ideas)

### Vocal Processing
- Vocal stem came pre-processed to save CPU
- Re-pitched down for darker character
- Layered with spoken whisper sections
- Ad-libs cut together for epic outro moment

### Bass & Low End
- Clean sub sine wave foundation
- Different fundamental frequencies explored during production
- Low-pass filtering in outro sections
- Low mids pushed intensely
- "German bass" — scientifically correct, very linear arrangement

### Arrangement
- Neurofunk structure with organic feel
- Outro shifts to more vulnerable, jam-like section
- Syncopation changes for emotional impact
- Minimal but effective FX
- Filter sweeps for transitions instead of heavy FX

### Mixing Approach
- Warm signal chain
- Gentle compression
- Saturation for character
- Clear low end priority
- Different kick low end for groove variation
