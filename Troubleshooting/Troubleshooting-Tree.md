# Troubleshooting System

---

## Problem: Weak Bass

### Diagnosis
1. **Is sub present?**
   - Yes: Go to "Sub present" → Check levels
   - No: Go to "No sub"

2. **No sub:**
   - Add pure sine at fundamental
   - Increase gain 3-6 dB
   - Check for phase issues

3. **Sub present but weak:**
   - Check kick pitch lock
   - Reduce competing frequencies
   - Sidechain to kick

4. **Muddy low end:**
   - Cut 150-300 Hz on bass
   - Cut 200-400 Hz on other elements
   - Increase sub/mid separation

---

## Problem: Weak Kick

### Diagnosis
1. **Transients soft?**
   - Boost 3-5 kHz
   - Increase attack
   - Reduce compression

2. **Body missing?**
   - Boost 50-80 Hz
   - Add saturation
   - Check pitch lock

3. **Getting masked?**
   - Sidechain bass to kick
   - EQ carve around kick
   - Reduce competing elements

4. **Punch missing?**
   - Faster attack time
   - Reduce release time
   - Parallel compression

---

## Problem: Muddy Mix

### Diagnosis
1. **Which range?**
   - Low (20-150 Hz): See "Weak Bass"
   - Low-mid (150-400 Hz): Cut competing elements
   - Mid (400-2 kHz): Reduce honk

2. **Low-mid solution:**
   - High-pass everything except bass/kick
   - Cut 200-400 Hz on guitars/pads
   - Sidechain competing elements to bass

3. **General cleanup:**
   - Mute unused elements
   - Reduce unnecessary frequencies
   - Check for accumulation

---

## Problem: Poor Stereo

### Diagnosis
1. **Mono compatible?**
   - Collapse in mono: Fix center content
   - Fine in mono: Width issue

2. **No width:**
   - Add stereo modulation
   - Use mid-side EQ
   - Duplicate and offset (Haas)

3. **Too wide:**
   - Reduce side signal
   - Center essential elements
   - Check mono sum

---

## Problem: Empty Arrangement

### Diagnosis
1. **Section duration?**
   - Too long: Trim to 8-16 bars
   - Too short: Extend to 8-16 bars

2. **Energy flat?**
   - Add filter sweeps
   - Add automation
   - Layer FX builds

3. **No dynamics?**
   - Create contrast sections
   - Strip down for breakdown
   - Build back up

---

## Problem: Low Energy

### Diagnosis
1. **Drop weak?**
   - Add layers (noise, texture, FX)
   - Increase distortion
   - Add risers/pre-breaks

2. **Arrangement flat?**
   - Create peaks/valleys
   - Add vocal/shout samples
   - Use automation rides

3. **Mix lacks impact?**
   - Increase kick/bass relationship
   - Add saturation/distortion
   - Increase master bus limiting

---

## Problem: Weak Master

### Diagnosis
1. **Dynamic range?**
   - Too wide: Increase limiting
   - Too narrow: Reduce compression

2. **Loudness?**
   - Add multiband limiting
   - Increase brick wall ceiling
   - Check low-end headroom

3. **Clarity?**
   - Tame low mids
   - Air boost
   | Check high-frequency limit
