# Workflow Map

---

## Production Flow
1. Start with the dashboard
2. Open the build sheet for a new track
3. Define the session goal
4. Use the appropriate checklist
5. Work in focused blocks
6. Review progress and save the version

## Decision Flow
- Stuck? Use the decision tree
- Need structure? Use the arrangement checklist
- Need low end clarity? Use the low end system
- Need mix help? Use the mixing system
- Need a reference breakdown? Use the reference analysis framework

## Output Flow
- Draft -> Arrange -> Mix -> Master -> Export
