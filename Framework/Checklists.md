# Production Checklists

---

## Daily Session Checklist

- [ ] Review yesterday's work (5 min)
- [ ] Set session goal (one sentence)
- [ ] Load reference track
- [ ] Check monitoring volume
- [ ] Set timer (90 min max)
- [ ] Work in 25 min chunks
- [ ] Save version per chunk
- [ ] Break if stuck > 15 min
- [ ] Document session notes

---

## Sound Design Checklist

**Before starting:**
- [ ] Clear existing layers
- [ ] Set gain staging
- [ ] Define layer function

**During:**
- [ ] Design one layer at a time
- [ ] Test in mix context
- [ ] Document decisions
- [ ] Save preset with notes

**After:**
- [ ] Check mono compatibility
- [ ] Compare to reference
- [ ] Verify layer function

---

## Mixing Checklist

**Setup:**
- [ ] Clear all mix plugins
- [ ] Set reference levels
- [ ] Check stereo image
- [ ] Zero all faders

**Foundation:**
- [ ] Position kick
- [ ] Position bass
- [ ] Position snare
- [ ] Rough balance

**Processing (per channel):**
- [ ] EQ (cut first, then boost)
- [ ] Compression
- [ ] Saturation
- [ ] FX send/return

**Final:**
- [ ] Stereo imaging
- [ ] Mono check
- [ ] Reference comparison
- [ ] Gain staging check

---

## Arrangement Checklist

**Structure:**
- [ ] Define sections
- [ ] Map energy flow
- [ ] Mark transitions

**Content:**
- [ ] Fill each section
- [ ] Vary elements per section
- [ ] Add/remove layers appropriately

**Dynamics:**
- [ ] Automation pass
- [ ] Volume rides
- [ ] Filter movements

---

## Export Checklist

- [ ] True peak below -1 dB
- [ ] LUFS target (-7 to -4 typical)
- [ ] Mono compatible
- [ ] Check on multiple systems
- [ ] A/B with reference
- [ ] Tag with version number
