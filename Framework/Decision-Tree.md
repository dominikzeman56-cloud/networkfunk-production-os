## Decision Framework

### "Is this working?"
- Yes → Move on
- No → Identify problem

### "Is it finished?"
- Better than reference? → Yes
- Matches quality target? → Yes
- No → Continue

### "Should I render?"
- Need to process audio? → Yes
- CPU limit reached? → Yes
- Otherwise → Stay in MIDI

### "Should I add more?"
- Does it serve one function? → Yes
- Does it enhance the mix? → Yes
- Otherwise → No

## Common Next Steps

| Situation | Next Action |
|-----------|-------------|
| Empty session | Set tempo, load reference |
| Loop feeling stale | Change hi-hat rhythm |
| Weak bass | Check sub level first |
| Muddy mix | High-pass non-bass elements |
| Kick-bass clash | Pitch lock + sidechain |
| Arrangement flat | Automate filter/cutoff |
| Mix not translating | Check mono compatibility |
| Sounds generic | Add noise/texture layer |
| Energy dropping | Add riser/transitional FX |
| Everything competing | Subtract, don't add |
