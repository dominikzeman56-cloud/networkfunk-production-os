# Project Checklist

---

## Before the first session
- [ ] Define the reference track
- [ ] Lock tempo and key
- [ ] Choose the bass approach
- [ ] Decide the drum direction
- [ ] Make a rough arrangement map

## During production
- [ ] Keep one layer = one function
- [ ] Test each element in the mix
- [ ] Save versions regularly
- [ ] Use the decision tree when stuck
- [ ] Keep the session goal visible

## Before finishing
- [ ] Check the low end
- [ ] Check the drums
- [ ] Check the stereo balance
- [ ] Compare to reference
- [ ] Export with a clear naming scheme
