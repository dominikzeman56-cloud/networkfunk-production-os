# Neurofunk Production OS (NPOS)

**Production operating system for modern Neurofunk and Drum & Bass.**

NPOS is designed to be used during production sessions, not only read. The goal is to help you make better decisions, move faster, and keep the workflow consistent.

---

## Quick Start

1. Open [[Dashboard]] for the current session view
2. Start a new track with [[Build-Sheet]]
3. Plan the session with [[Session-Management/Session-Planner]]
4. Use [[Framework/Decision-Tree]] when stuck
5. Analyse references with [[Framework/Reference-Analysis-Framework]]

---

## Core Architecture

- **Framework**: decision trees, checklists, workflows, templates
- **Knowledge**: engineering knowledge for bass, drums, mixing, arrangement, FX, and more
- **Case Studies**: repeatable track analysis structure
- **Producer Knowledge**: production philosophy, not biography
- **Presets**: recurring production patterns, not isolated preset dumps
- **AI**: production mentor guidance, not encyclopedic answers

---

## Core Principles

- **Decision system, not encyclopedia**
- **Sound design = mixing**
- **Stay in MIDI**
- **One layer = one function**
- **Producers = philosophies, not copies**
- **Transform knowledge into action**
