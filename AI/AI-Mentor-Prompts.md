# AI Mentor Prompts

---

## Quick Questions

### Sound Design
```
"I'm designing [element]. Stage: [foundation/mixing/mastering].
What layer structure applies?"
```

### Arrangement
```
"My [section] feels [problem]. Stage: [arrangement/mixing].
What decision tree applies?"
```

### Mixing
"[element] competing with [element]. Stage: mixing.
Give me 3 concrete checks."

### Troubleshooting
"[problem]. I tried [attempts].
What's the next step?"

---

## Extended Questions

### Bass Design
```
Context: Building neurofunk bass
Stage: Sound design - layer 3
Current: Sub and Body done, need Movement
Question: What movement techniques work for reese bass?
Constraint: Keep groov, don't kill sub focus
```

### Drum Programming
```
Context: Creating drum groove
Stage: Foundation
Current: Kick pattern done, snare feels flat
Question: Give me 3 snare variations for neurofunk
Constraint: Tight, aggressive, tempo: [X]
```

### Mixing Decision
```
Context: Kick and bass masking
Stage: Mixing
Current: Tried sidechain (-3dB), still muddy
Question: What's my next move?
Constraint: Keep bass heavy, don't lose kick punch
```

### Arrangement Help
```
Context: Building to drop
Stage: Arrangement
Current: 16 bars built, energy plateau
Question: How to create the final push before drop?
Constraint: Use filters/risers, no new melodic content
```

---

## Response Format

AI should respond with:

1. **Production Stage** (1 line)
2. **Decision/Framework** (1 line)
3. **Next Concrete Step** (specific action)
4. **If stuck, try** (backup plan)

Example:
```
Stage: Mixing - bass clarity
Framework: Bass-Checklist
Next step: Cut 200-400 Hz on bass, check in mix context
If stuck: Solo bass + kick, adjust pitch lock relationship
```

---

## What Not To Ask

- "Explain FM synthesis theory"
- "Give me a list of all bass types"
- "How does compression work?"
- "What's the history of drum & bass?"

What to ask instead:
- "My FM bass sounds tinny. Stage: mixing. Fix?"
- "Need bass archetype for dark neurofunk. Recommend?"
