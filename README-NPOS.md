# NPOS - Neurofunk Production OS

Production operating system for modern Neurofunk and Drum & Bass.

## Project Structure

```
NPOS/
├── web/              # Astro web dashboard
├── server/           # Streamlit local server
├── .claude/          # Claude configuration
├── AI/               # AI guidance and prompts
├── Framework/        # Decision trees, checklists, workflows
├── Knowledge/        # Engineering knowledge
├── Presets/          # Preset analysis framework
├── Producer-Knowledge/ # Producer philosophies
├── Session-Management/ # Dashboard, build sheet, planner
├── Templates/        # Production templates
└── Troubleshooting/  # Problem-solving guides
```

## Quick Start

### Web Dashboard
```bash
cd web
npm install
npm run dev
```

### Local Tools
```bash
cd server
pip install -r requirements.txt
streamlit run apps/calculators.py
```

## Core Principle

**Workflow over information.** NPOS is a production tool, not an encyclopedia.
