# Daily Workflow

---

## Pre-Session (10 min)
1. Open NPOS Dashboard
2. Review today's goal
3. Load reference track
4. Clear workspace
5. Set timer (90 min session)

---

## Session Structure

### Chunk 1 (25 min)
- Work on primary goal
- No interruptions
- Version save at end

### Break (5 min)
- Stand, move
- Clear head

### Chunk 2 (25 min)
- Continue primary goal
- OR move to secondary task

### Break (5 min)

### Chunk 3 (25 min)
- Final push
- Document findings
- Set up tomorrow

---

## Post-Session (5 min)
1. What worked?
2. What didn't?
3. Tomorrow's goal?
4. Save & backup
5. Close all projects

---

## Session Types

### Sound Design Focus
- Reference listening
- Design one layer at a time
- Test in mix context
- Document presets

### Arrangement Focus
- Structure first
- Energy flow second
- Fill sections
- Add transitions

### Mixing Focus
- Foundation elements first
- Gain staging check
- Low end check first
- Reference comparison

### Export Focus
- Mix check
- Loudsness targeting
- True peak check
- Multi-system test
