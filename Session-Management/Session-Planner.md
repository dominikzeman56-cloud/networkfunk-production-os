# Session Planner

---

## Core Rule
Every session starts with one clear objective.

Do not begin a production session without answering:

- What am I finishing today?
- What is the next concrete action?
- What should I stop doing?

---

## Session Structure

### Pre-Session (10 min)
1. Open [[Session-Management/Dashboard]]
2. Review today's goal
3. Load reference track
4. Set timer for one focused block
5. Clear distractions

### Block 1 (25 min)
- Work on the primary objective only
- Avoid side quests
- Save a version at the end

### Break (5 min)
- Stand up
- Listen back
- Note what is working

### Block 2 (25 min)
- Continue the same objective
- Or shift to the next most important action

### Break (5 min)

### Block 3 (25 min)
- Finish the task
- Capture notes
- Prepare the next session

### Post-Session (5 min)
- What worked?
- What should change?
- What is tomorrow's goal?

---

## Session Types

### Sound Design Focus
- Define one layer at a time
- Test in mix context
- Keep the layer function clear

### Arrangement Focus
- Map sections first
- Build energy intentionally
- Add transitions and variation

### Mixing Focus
- Start with low end and balance
- Compare to reference often
- Check mono compatibility

### Export Focus
- Verify loudness and peaks
- Check translation on another system
- Save final versions clearly
